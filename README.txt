SMART EMERGENCY RESPONSE PORTAL
Diploma 3rd Year Computer Engineering Project

Technology: HTML, CSS, PHP, MySQL, XAMPP.

SETUP:
1. Install XAMPP.
2. Copy this folder to C:\xampp\htdocs\
3. Start Apache and MySQL.
4. Open http://localhost/phpmyadmin
5. Create database 'serp' OR import database.sql (it creates serp automatically).
6. Open http://localhost/Smart_Emergency_Response_Portal/
7. Register a citizen and submit an emergency report.
8. Admin: http://localhost/Smart_Emergency_Response_Portal/admin/login.php
   Username: admin
   Password: admin123

This is an academic prototype. Emergency services in real life should use official emergency numbers and established systems.
